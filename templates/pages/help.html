{% trans "Parcours IBTIKAR" context "help-current" %}

  1. {% trans "Avant une nouvelle demande, déclarez votre solde IBTIKAR résiduel dans le tableau de bord. Actualisez-le selon votre solde réel, y compris après des prestations effectuées sur une autre plateforme." context "help-current" %}
  2. {% trans "Ouvrez « Nouvelle demande », sélectionnez le service, renseignez les paramètres et les échantillons, puis vérifiez et soumettez. Le coût calculé est contrôlé par rapport au solde déclaré." context "help-current" %}
  3. {% trans "La demande passe par les validations pédagogique et financière, puis par la génération de la note de plateforme. Attendez les instructions de soumission IBTIKAR dans le suivi." context "help-current" %}
  4. {% trans "Quand ces instructions apparaissent, téléchargez le formulaire IBTIKAR, soumettez votre demande sur le site IBTIKAR-DGRSDT via le lien proposé, puis revenez dans PLAGENOR et saisissez le code de la demande externe." context "help-current" %}
  5. {% trans "Après transmission du code, la plateforme affecte la demande et propose un rendez-vous. Confirmez la date ou proposez une autre date avec les actions affichées." context "help-current" %}
  6. {% trans "La réception des échantillons et les étapes de réalisation sont enregistrées dans le suivi. Le rapport est déposé, validé puis transmis. Téléchargez-le et confirmez sa réception ; la plateforme peut ensuite clôturer la demande." context "help-current" %}

{% trans "Parcours des prestations sur devis" context "help-current" %}

  1. {% trans "Soumettez les informations de la prestation et des échantillons. La plateforme prépare puis envoie le devis ; consultez-le dans votre demande." context "help-current" %}
  2. {% trans "Acceptez ou refusez le devis avec les boutons disponibles. Après un refus, la plateforme peut préparer une nouvelle proposition. Après acceptation, déposez le bon de commande." context "help-current" %}
  3. {% trans "La plateforme émet la facture après le dépôt du bon de commande, puis affecte la prestation. Confirmez le rendez-vous proposé ou suggérez une autre date ; la réception des échantillons et la réalisation sont ensuite suivies dans la demande." context "help-current" %}
  4. {% trans "Après la fin de la réalisation, au statut « En attente paiement », réglez selon la facture et déposez le justificatif demandé. Un bon ou ordre de paiement déposé ne confirme pas à lui seul le règlement." context "help-current" %}
  5. {% trans "Le responsable habilité vérifie le paiement. Si le justificatif est refusé, la demande revient en attente de paiement. Après confirmation, le rapport peut être déposé, validé et transmis." context "help-current" %}
  6. {% trans "Téléchargez le rapport transmis et confirmez sa réception. La plateforme peut ensuite archiver la demande." context "help-current" %}
