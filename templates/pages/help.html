🚀 {% trans "Bien démarrer" %}

{% trans "Créer un compte et comprendre les deux canaux." %}

  1. {% blocktrans %}Cliquez sur Inscription en haut à droite et remplissez vos informations (nom, établissement, wilaya, e-mail).{% endblocktrans %}
  2. {% blocktrans %}Choisissez votre profil : Demandeur IBTIKAR (étudiant/chercheur, budget annuel encadré) ou Client GENOCLAB (prestation commerciale avec devis).{% endblocktrans %}
  3. {% blocktrans %}Connectez-vous : vous arrivez sur votre tableau de bord personnel.{% endblocktrans %}

{# ---- Requester (IBTIKAR) -------------------------------------------- #}

🎓 {% trans "Soumettre une demande IBTIKAR" context "help" %}{% if user_role == 'REQUESTER' %}{% trans "Vous" %}{% endif %}

{% trans "Pour les étudiants et chercheurs de l'ESSBO." %}

  1. {% blocktrans %}Dans votre tableau de bord, ouvrez l'onglet Nouvelle demande.{% endblocktrans %}
  2. {% blocktrans %}Sélectionnez le service souhaité (ex. PCR, MALDI-TOF, Séquençage…).{% endblocktrans %}
  3. {% blocktrans %}Remplissez les questions du service (type de kit, contrôle qualité…) et le tableau d'échantillons. Le coût estimé se met à jour en direct.{% endblocktrans %}
  4. {% blocktrans %}Vérifiez votre budget IBTIKAR annuel restant affiché en haut — la demande est bloquée si elle dépasse le plafond.{% endblocktrans %}
  5. {% blocktrans %}Cliquez sur Vérifier et soumettre. Vous recevez une confirmation par e-mail avec votre identifiant de demande.{% endblocktrans %}
{# ---- Client (GENOCLAB) ---------------------------------------------- #}

🏢 {% trans "Demande GENOCLAB (commercial)" context "help" %}{% if user_role == 'CLIENT' %}{% trans "Vous" %}{% endif %}

{% trans "Pour les entreprises, laboratoires et institutions externes." %}

  1. {% blocktrans %}Soumettez votre demande avec les détails de l'analyse et vos échantillons.{% endblocktrans %}
  2. {% blocktrans %}La plateforme prépare un devis détaillé que vous recevez par e-mail.{% endblocktrans %}
  3. {% blocktrans %}Acceptez ou refusez le devis. En cas de refus, l'équipe peut vous en proposer un nouveau.{% endblocktrans %}
  4. {% blocktrans %}Téléversez votre bon de commande, puis réglez selon la facture émise.{% endblocktrans %}
  5. {% blocktrans %}L'analyse démarre ; vous recevez le rapport final avec la facture.{% endblocktrans %}
{# ---- Tracking ------------------------------------------------------- #}

🔍 {% trans "Suivre une demande & récupérer un rapport" %}

{% trans "Où en est votre analyse, à tout moment." %}

  1. {% blocktrans %}Connecté : chaque demande affiche son statut en temps réel et son historique complet sur votre tableau de bord.{% endblocktrans %}
  2. {% blocktrans %}Invité : utilisez la page Suivi avec le code reçu par e-mail à la soumission.{% endblocktrans %}
  3. {% blocktrans %}Vous recevez un e-mail à chaque étape (validation, assignation, rendez-vous, rapport prêt).{% endblocktrans %}
  4. {% blocktrans %}Quand le rapport est validé, un lien de téléchargement sécurisé vous est envoyé.{% endblocktrans %}
